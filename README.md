# University Management System

A beginner-level university management system developed to practice basic programming concepts and Object-Oriented Programming (OOP).

## 📌 About the Project

This project is a simple university management system that manages basic information about students, teachers, and courses.

The system also includes basic academic and financial calculations, such as calculating a student's GPA based on course grades and credits, as well as calculating a teacher's income based on the number of teaching credits.

## ✨ Features

- Add, edit, and delete students
- Add, edit, and delete teachers
- Manage course credits
- Record student grades
- Calculate student GPA
- Calculate teacher income based on teaching credits
- Display student and teacher information

## 🛠️ Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
